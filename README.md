# Аудит НИОКР — экспертная оценка актуальности, целесообразности и результативности (ЭО-НИОКР)

**Текущая версия: v22.1 · методика ЭО-НИОКР v2.1 · этапы 22–23 · 11.11.2026**

Автономный комплект инструментов для коллегиальной экспертной оценки НИОКР: помогает обоснованно решить, сохраняется ли потребность в результате работ и стоит ли их продолжать. Комплект работает **офлайн, без установки, без макросов и без внешних зависимостей** — HTML-программа открывается двойным кликом в браузере, Excel-калькулятор считает формулами.

> **Назначение README.** Файл ведётся в корне репозитория и **обновляется после каждой итерации**: в журнал ниже добавляется запись «что сделано», обновляются текущая версия, состав пакета и результаты проверок.

### 1.1. Предыдущая итерация — этап 22 (v22.0): математический аппарат

Задача итерации: **доработать программу и чек-лист в части математического аппарата — чтобы повысить обоснованность решения, принимаемого после экспертной оценки**, и завести корневой README.md с описанием сделанного.

До этапа 22 инструменты показывали *какое* решение получается (индексы, зоны, рекомендация), но не показывали, *насколько надёжна* экспертная оценка, стоящая за ним. Добавлен **диагностический слой обоснованности**:

| Что добавлено | Смысл для комиссии |
| --- | --- |
| **Доверительные интервалы 95 %** для I_A и I_C: `m ± t(0,975; n−1)·s/√n` | Показывает погрешность группового индекса при малом числе экспертов. Если интервал пересекает границу зоны (В ≥ 4,00 / С ≥ 3,00 / Н < 3,00) — зона помечается **«НЕ УСТОЙЧИВА»**: решение опирается на спорную границу |
| **W Кендалла** (конкорданс) с поправкой на связки + **χ² = m(k−1)·W** и проверка значимости | Показывает, согласованно ли эксперты ранжируют вопросы: по всем 22 и отдельно по блокам А (10) и Ц (12). Шкала: < 0,30 слабое · < 0,50 умеренное · < 0,70 заметное · ≥ 0,70 высокое |
| **Jackknife (leave-one-out)** | Пересчёт без каждого эксперта поочерёдно: сколько раз меняется рекомендация и каков максимальный сдвиг индексов. Выявляет решения, зависящие от одного мнения |
| **Взвешенная SE с поправкой Бесселя** и **n_eff Киша** `(Σw)²/Σw²` | Корректная погрешность при неравных весах; при равных весах формула сводится к обычной `s/√n`, а n_eff = n |
| **Ворота G1–G5** и **вердикт** | Готовая повестка заседания: что именно мешает считать оценку надёжной |
| **Протокол обоснованности (приложение №13)** | Печатная форма, прикладываемая к протоколу заседания |

**Ворота и вердикт**

| Ворота | Проверяется |
| --- | --- |
| G1 | Полнота: у всех экспертов 22 из 22 числовых оценок, Н/О отсутствуют |
| G2 | Согласие: W по 22 вопросам ≥ 0,50 **и** χ² значим (α = 0,05) |
| G3 | Устойчивость зон: ДИ I_A и I_C не пересекают границу зоны |
| G4 | Jackknife: исключение любого эксперта не меняет рекомендацию |
| G5 | Нет флагов: повопросных σ > 1,00 и групповых «красных» сигналов |

5 из 5 → «Решение статистически обосновано» · 3–4 → «Обосновано с оговорками» · ≤ 2 → «Требуется доработка экспертной оценки» · n < 3 → «Недостаточно экспертов для статистической оценки».

**Принципиальное ограничение:** слой **диагностический**. Он не меняет индексы, зоны, матрицу 3×3, оверрайд стоп-фактора, рекомендацию и решение комиссии. Вердикт «5 из 5» не означает «продолжить НИОКР», а «≤ 2» не означает «прекратить». Итоговое решение принимает комиссия.

**Изменения по файлам**

- **HTML-модель v22.0** — модуль `MATH` (t- и χ²-таблицы, median, stdevS, ciStat, kendallW, justOf); карточка «Обоснованность решения» на вкладке «Сводная оценка»; кнопки «📊 Обоснованность» и «🖨 Протокол обоснованности»; колонка «Обоснованность» в портфельном CSV (18 колонок); публичный API `just/kendallW/ciStat/median/stdevS/printJust`.
- **Excel v22 — 19 листов**: новый лист **«Обоснованность»** (t-таблица и χ²-критические, повопросные ранги, ДИ индексов, W по 22/А/Ц, jackknife по экспертам, ворота G1–G5, счётчик и вердикт); вердикт продублирован в «Свод» и «Панель». Всё формулами, без макросов.
- **Методика ЭО-НИОКР v2.1** — новый **§21** из 8 подразделов и **приложение №13** (форма протокола). Разделы 1–20 и приложения №1–12 сохранены.
- **Инструкция пользователя v22** — новый раздел 8а (как читать ДИ, W, jackknife, ворота; порядок применения; ограничения), обновлённые FAQ.
- **Презентация v22 — 14 слайдов** (слайды «Статистическая обоснованность решения» и «Обоснованность на учебном стенде» с реальными числами стенда).
- **Сценарий апробации v22** — §6.1 (таблица обоснованности стенда) и §9Б (заполненный протокол приложения №13), новые критерии, риски и пункты чек-листа готовности.
- **Исправлен дефект модели**: взвешенная SE не сводилась к `s/√n` при равных весах — введена поправка Бесселя `s_w² = Σw(x−m_w)² / (Σw − Σw²/Σw)`, `SE = √(s_w²·Σw²)/Σw`. Инвариант закреплён тестом.
- **Формат данных не менялся** — сохранения v19/v20/v21 открываются без миграции.

**Проверки этапа 22:** `test_v22.js` — **330 / 0**; QA-зонд `_qa22_probe.js` — **28 / 28**; `verify_10_xlsx_22.py` — **338 / 0** (независимый пересчёт формул, 22 контрольных примера).

## 3. Неизменный базис методики v1.0

Состав инструментария не меняется ни при каких режимах и версиях:

- **22 основных вопроса** = 10 (актуальность, А1–А10) + 12 (целесообразность, Ц1–Ц12);
- единая шкала **1–5** с отметкой **Н/О** («не оцениваю»); **Н/О — не балл** и не приравнивается к 3, исключается из знаменателя;
- **5 стоп-факторов** (СФ1–СФ5): «Да» хотя бы у одного эксперта блокирует авто-рекомендацию «Продолжить НИОКР» (понижается до «Пересмотреть»);
- **9 «красных» вопросов** (КВ1–КВ9): групповой сигнал требует **≥ 2 экспертов**;
- индексы **I_A** и **I_C** (1,00–5,00), общего балла нет; зоны **В ≥ 4,00 · С ≥ 3,00 · Н < 3,00**;
- **матрица решений 3×3** с оверрайдом стоп-фактора;
- согласованность **σ популяционное**: 0,50 / 0,80 / 1,00; σ > 1,00 — обязательное обсуждение;
- полнота анкеты: минимум 8 из 10 (А) и 10 из 12 (Ц);
- группа **3–10 экспертов**; равные веса по умолчанию;
- **документарное подтверждение баллов не требуется** — оценивается суждение компетентных специалистов;
- итоговое решение принимает **комиссия**.

## 4. Быстрый старт

1. Откройте `output/Аудит_НИОКР_интерактивная_модель.html` двойным кликом (работает офлайн).
2. Нажмите **«🧪 Демо → Портфель демо: 5 НИОКР»** — загрузится учебный стенд с контрольными значениями.
3. Вкладка **«Сводная оценка»** → карточка **«Обоснованность решения»** → «📊 Обоснованность» (подробные таблицы) и «🖨 Протокол обоснованности» (печать формы прил. №13).
4. Для бумажной процедуры: **«Бланк анкеты»** в модели или лист **«Анкета_бланк»** в Excel.
5. Excel-вариант: `output/10_Чек-лист_ЭО_НИОКР_22_вопроса_v22.xlsx` — анкеты Э1–Э10 → «Свод» → «Обоснованность» → «Панель» / «Заключение».

| НИОКР | I_A | I_C | Рекомендация | W | Ворот | Вердикт |
| --- | --- | --- | --- | --- | --- | --- |
| БПЛА-СУ-24 | 4,50 | 4,25 | Продолжить НИОКР | 0,8854 | 4/5 (G3) | Обосновано с оговорками |
| МАТ-ЛИТ-25 | 4,33 | 3,27 | Продолжить с корректировкой | 0,9577 | 5/5 | Решение статистически обосновано |
| ЦД-ГТД-23 | 3,30 | 3,33 | Пересмотреть параметры НИОКР | 0,7731 | 3/5 (G3, G5) | Обосновано с оговорками |

## 8. Ограничения

- Малое число экспертов (3–5) даёт широкие доверительные интервалы; t- и χ²-приближения на таких выборках ориентировочные.
- W Кендалла измеряет согласие о **порядке** вопросов, а не об уровне баллов: высокий W не означает высоких оценок.
- Jackknife показывает чувствительность решения, но не его «правильность».
- Комплект не заменяет техническую экспертизу, приёмку, испытания и финансовый контроль.
- Запрещено править баллы ради прохождения ворот; изменение оценок допускается только через раунд 2 с сохранением исходных.
