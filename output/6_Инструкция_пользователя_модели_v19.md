# ИНСТРУКЦИЯ ПОЛЬЗОВАТЕЛЯ — интерактивная модель ЭО-НИОКР v19.0

**Файл:** `output/Аудит_НИОКР_интерактивная_модель.html` (автономный HTML, снимок `output/versions/Аудит_НИОКР_модель_v19.0.html`). Откройте двойным кликом — работает офлайн в любом современном браузере, установка не требуется.

Модель реализует **Методику экспертной оценки актуальности и целесообразности НИОКР (ЭО-НИОКР v1.0)**: ровно 22 основных вопроса (10 актуальность + 12 целесообразность), единая шкала 1–5 с отметкой Н/О, 5 стоп-факторов, 9 «красных» вопросов, два индекса I_A и I_C, матрица решений 3×3 с оверрайдом стоп-фактора, σ-согласованность мнений. Документальное подтверждение баллов не требуется.

## 1. Быстрый старт

1. Откройте файл. Вкладка **«📊 Дашборд»** — заполните карточку объекта (наименование, шифр, исполнитель, заказчик, дата).
2. Вкладка **«🧮 Анкеты экспертов»** — выберите эксперта Э1…Э5 (чипы сверху), укажите Ф.И.О., компетенцию, дату. Каждый эксперт заполняет **свою** анкету изолированно.
3. По каждому из 22 вопросов нажмите балл 1–5 или «Н/О» (повторный клик снимает ответ). Разверните «якоря шкалы 1–5» под вопросом, если нужна опора; «разграничение» — для близких пар вопросов.
4. Заполните блоки **«Стоп-факторы»** (Да / Нет / Неопределённо) и **«Красные вопросы»** (1–5: 1=Да … 5=Нет).
5. Индивидуальные индексы I_A/I_C эксперта считаются сразу под разделами (с правилом минимальной полноты: ≤2 Н/О на направление).
6. **«📋 Сводная оценка»** и **«📈 Панель»** — групповые индексы, σ, повопросная статистика (среднее/min/max/разброс/σ/флаги), групповые сигналы СФ и КВ, матрица с активной ячейкой, графики.
7. **«📄 Заключение и протокол»** — автоматический текст заключения из 9 разделов + протокол комиссии (рекомендация из 5 вариантов, обоснование, особые мнения, подписи). Кнопки: печать/PDF, копирование в Word, выгрузка чек-листа в Markdown.
8. **«📚 Методика»** — операционный справочник: шкала, правила, якоря 1–5 по всем 22 вопросам, СФ/КВ, регламент, периодичность, апробация. Есть поиск по разделу.

## 2. Правила расчёта (памятка)

| Что | Правило |
| --- | --- |
| I_A эксперта | ΣA_i / N_A по 10 вопросам; Н/О исключены из знаменателя; минимум 8 оценённых, иначе «НЕ РАССЧИТАН» |
| I_C эксперта | ΣC_j / N_C по 12 вопросам; минимум 10 оценённых |
| Групповые I_A, I_C | простое среднее индивидуальных индексов экспертов с действующей оценкой (веса равные) |
| Зоны | В 4,00–5,00 · С 3,00–3,99 · Н 1,00–2,99 |
| σ | популяционное стандартное отклонение; ≤0,50 высокая · ≤0,80 приемлемая · ≤1,00 умеренные · >1,00 существенные разногласия (обсуждение, исходные оценки сохраняются) |
| Повопросные флаги | σ>1,00 → «РАЗНОГЛАСИЕ»; среднее ≤2 → «НИЗКАЯ» |
| Стоп-факторы | «Да» хотя бы у одного эксперта → ВЫЯВЛЕН: рекомендация «Продолжить НИОКР» автоматически понижается до «Пересмотреть параметры НИОКР (стоп-фактор)»; «Неопределённо» без «Да» → НЕОПРЕДЕЛЁН |
| «Красные» сигналы | негативные (КВ1–6, 9): балл 1–2; позитивные (КВ7–8): балл 4–5; групповой сигнал при ≥2 экспертах; единичный — особое мнение |
| Матрица | 3×3 по зонам (I_A ↓ × I_C →); при отсутствии одного из индексов рекомендация не формируется |

## 3. Сервисные функции

- **⬇ JSON / ⬆ JSON** — экспорт и импорт состояния (только формат v19); **Ctrl+S** — быстрый экспорт.
- **🖨 Печать** — печатает активную вкладку (заключение/протокол — для PDF и подписей).
- **☾** — тёмная тема; **?** — справка; **🧪 Демо** — контрольные ситуации апробации С-1/С-2/С-3 (заполняют 3 анкеты эталонными паттернами) и полная очистка.
- Автосохранение в localStorage браузера (переживает перезагрузку страницы).
- Горячие клавиши: **1–6** вкладки, **t** тема, **d** демо, **?** справка, **Esc** закрыть окно.
- **Экспорт CSV** на вкладке «Свод» — сводная таблица для внешних отчётов; **⬇ Чек-лист (MD)** на вкладке «Заключение» — заполненный чек-лист в Markdown для Word.

## 4. Роли и дисциплина процедуры

- **Эксперт** — заполняет только свою анкету, до обсуждения не видит оценок коллег.
- **Секретарь** — вносит данные, печатает сводку; **не изменяет баллы**, не трактует Н/О как 3.
- **Председатель** — ведёт заседание и подписывает протокол; его балл весит как любой другой.
- **Руководитель НИОКР** — приглашается для пояснений, не оценивает и не голосует.
- Комиссия не обязана приходить к единому мнению; разногласие фиксируется как результат.

## 5. Апробация (пилот)

Кнопка «🧪 Демо» заполняет три контрольные ситуации: С-1 «актуальная, но нереализуемая» (ожидается В/Н → «Пересмотреть содержание и способ реализации»), С-2 «реализуемая, но устаревшая» (Н/В → «Пересмотреть необходимость и назначение работ» + СФ1), С-3 «перспективная, но без потребителя» (С/С → «Пересмотреть параметры НИОКР» + КВ7/КВ8). Сравните фактический результат с ожидаемым; вопросы с σ>1,00 — кандидаты на переписывание якорей (состав 22 вопросов не меняется).

## 6. Частые вопросы

- **Почему нет общего балла?** Единый балл скрывает принципиальные проблемы (высокая актуальность компенсирует нулевую целесообразность). Решение — по паре индексов.
- **Когда ставить Н/О, а когда 3?** Н/О — «я не компетентен» (о эксперте); 3 — «признак промежуточный, обстоятельства сопоставимы» (о НИОКР).
- **Эксперт поставил 1 или 5 без комментария?** Блокировки нет: комментарий рекомендован, но не обязателен (методика экспертная, не документарная).
- **Стоп-фактор «Неопределённо» — это выявленный фактор?** Нет: комиссия решает, нужно ли дополнительное изучение; блокировка рекомендации возникает только при «Да».
- **Данные прошлых версий (v18, 15/30/60) переносятся?** Нет: v19.0 — методический перезапуск (ЭО-НИОКР v1.0). Исторические модели v1.0–v18.0 сохранены в `output/versions/` и читают свои сохранения.
