# ИНСТРУКЦИЯ ПОЛЬЗОВАТЕЛЯ

## Интерактивная модель аудита НИОКР, v4.0

Файл: `Аудит_НИОКР_интерактивная_модель.html` (единый автономный файл; история версий — `versions/Аудит_НИОКР_модель_v1.0…v4.0.html`, журнал — `VERSIONS.md`).

**Назначение:** проведение аудита актуальности, эффективности и целесообразности НИОКР по финальному чек-листу v2.0 (27 вопросов, 3 блока с весами 30/35/35) с автоматическим расчётом интегрального показателя I (0–100), обработкой ответов «Н/П», аналитикой устойчивости решения и формированием акта оценки.

**Требования:** любой современный браузер (Chrome, Edge, Firefox, Safari). Интернет не нужен: все стили, скрипты, изображения и база знаний встроены в файл. Данные хранятся локально в браузере (localStorage) и никуда не передаются.

---

## 1. Быстрый старт

1. Откройте файл двойным кликом.
2. При первом запуске появится приветственное окно — «Начать работу» (или «🧭 Тур» в верхней панели для пошагового знакомства).
3. Выберите НИОКР в селекторе верхней панели или добавьте новую кнопкой «＋ НИОКР».
4. Заполните чек-лист (вкладка «✅ Чек-лист»): по каждому вопросу выберите ответ, документальное подтверждение и при необходимости комментарий.
5. Результаты появятся мгновенно на вкладке «📊 Дашборд»; акт формируется на вкладке «🖨 Акт оценки».

## 3. Вкладки

**📊 Дашборд.** Интегральный показатель I и категория; gauge-диаграмма со зонами шкалы; радар профиля блоков; бары выполнения Pⱼ и взвешенные Bⱼ; тепловая карта 27 ответов (клик — переход к чек-листу); контрольные условия; лента уведомлений.

**✅ Чек-лист (27).** Три блока по 9 вопросов. По каждому вопросу: ответ («Да, полностью»=5 … «Нет»=0, «Н/П»), подтверждение («Да»/«Нет»), комментарий/документы. Строка итога блока показывает Sⱼ, Nⱼ, Pⱼ, Bⱼ. Правила: баллы 4–5 без подтверждения вызывают предупреждающий popup (снизить балл или зафиксировать риск); «Н/П» требует обоснования в popup.

**📈 Аналитика.** Сценарии «что-если» (сохранить копию ответов, сравнить дельты I, применить); торнадо-чувствительность (ΔI за +1 сырой балл блока; ΔI при весе +10 %); Монте-Карло (итерации, seed, гистограмма I, P10/P50/P90, вероятности категорий); снапшоты динамики I; карта портфеля «стоимость × I»; сводный акт по портфелю (печать).

**📄 Паспорт НИОКР.** Общие сведения; финансы (прогнозная итоговая стоимость и отклонение считаются автоматически); 7 контрольных условий со статусами; решение комиссии, обоснование и мероприятия.

**🗂 Портфель.** Матрица всех НИОКР (балл, категория, решение), donut-распределение по категориям, средний балл, добавление/удаление, экспорт CSV.

**📚 Справочник.** База знаний с поиском: методика и формулы; TRL/УГТ (NASA 1–9, ГОСТ Р 15.301-2016); экономика (NPV/IRR/PP); мировые практики (Horizon Europe, Stage-Gate, AHP); якоря баллов 5/3/0 по всем 27 вопросам; галерея (встроенные изображения и SVG-схемы); источники.

**🖨 Акт оценки.** Автозаполняемая форма итогового заключения: печать/PDF и копирование текста в Word.

## 5. Роли и разделение ответственности

| Роль | Права |
| --- | --- |
| Аудитор | полные права: баллы чек-листа, контрольные условия, решения, портфель |
| Подразделение | паспорт, финансы, комментарии; выставление баллов заблокировано (оценивает только комиссия) |
| Наблюдатель | только чтение |

Разделение реализует принцип методики: подразделение представляет доказательную картину, комиссия формирует независимую оценку.

## 6. Уведомления

- **Toast** — всплывающие сообщения справа сверху (оценки, предупреждения правил, категории, контрольные условия);
- **Лента** — история уведомлений сессии (кнопка 🔔 и блок на дашборде);
- **Push** — системные уведомления браузера после разрешения (кнопка «Разрешить push»); в средах без поддержки автоматически остаётся toast-режим.

## 7. Математика (памятка)

```
Sⱼ = Σ баллов применимых вопросов блока j      (0…45)
Nⱼ = число применимых вопросов блока j          (0…9)
Pⱼ = Sⱼ / (5·Nⱼ)                                (0…1)
Bⱼ = Wⱼ · P,   W = (30, 35, 35)
I  = 100 · Σ Bⱼ(прим.) / Σ Wⱼ(прим.)            (0…100)
```

«Н/П» исключает вопрос из числителя и знаменателя; блок целиком «Н/П» исключает свой вес с ренормировкой; все 27 «Н/П» → «Недостаточно данных». Шкала: 85–100 Высокая; 70–84 Хорошая; 50–69 Удовлетворительная; 30–49 Неудовлетворительная; 0–29 Критическая.

## 8. Данные, резервные копии, перенос

- Автосохранение в localStorage при каждом изменении; «Сохранить» — принудительно.
- «Экспорт JSON» — файл-копия всего портфеля (НИОКР, ответы, сценарии, снапшоты, решения); «Импорт» восстанавливает её на другом компьютере.
- «Экспорт CSV» на вкладке «Портфель» — сводная матрица для Excel.
- Очистка: удалить НИОКР кнопкой ✕ в портфеле; полный сброс — очистка данных сайта в браузере.

## 9. Контрольные точки качества (регрессия между версиями)

1. Базовый набор ответов даёт I = 72.9 и категорию «Хорошая».
2. Блок целиком «Н/П» → ренормировка весов.
3. Все 27 «Н/П» → «Недостаточно данных».
4. Балл 4/5 при подтверждении «Нет» → предупреждающий popup.
5. «Н/П» без обоснования → popup обоснования.
6. Выявленное контрольное условие → уведомление и учёт в акте.
7. Роли: «Подразделение» не может выставлять баллы; «Наблюдатель» — только чтение.
8. Экспорт/импорт JSON и CSV работают; данные переживают перезагрузку страницы.

## 10. Частые вопросы

- **Почему балл не ставится?** Проверьте роль (раздел 5) — баллы выставляет только «Аудитор».
- **Где взять обоснование «Н/П»?** Комментарий вопроса: обоснование обязательно, иначе вопрос считается применимым.
- **Как сравнить «до/после мероприятий»?** Вкладка «Аналитика»: сохраните сценарий «как есть», измените ответы, сохраните второй сценарий — таблица покажет дельту I.
- **Насколько устойчив вывод?** Монте-Карло на вкладке «Аналитика»: если P10 и P90 попадают в разные категории — решение чувствительно к погрешности оценок, соберите больше доказательств.
- **Печать акта не запускается?** Встроенный просмотрщик может блокировать window.print — используйте кнопку печати браузера после открытия вкладки «Акт оценки».
