## 3. Математическая модель (памятка)

- **v18.0:** три опросника (К 15 / С 30 / П 60); в каждом — три направления: Актуальность (I_А), Целесообразность (I_Ц), Результативность (I_Р). I_k = Σwᵢxᵢ/(5·Σwᵢ)·100 % по кодам направления; комплексный I = ∛(I_А·I_Ц·I_Р). «НП» исключается из индекса и из знаменателя Coverage (нужно письменное обоснование), «НД» — только из числителя Coverage. Пороги Coverage: 80 / 85 / 90 %; ниже порога положительное заключение не выносится. Уровни индексов: ≥85 «Высокий» · 70–84 «Приемлемый» · 55–69 «Проблемный» · <55 «Критический». Решение — по матрице 4×4 (I_А × I_Ц → R1–R7); подтверждённый стоп-фактор SF-2 → эскалация и запрет безусловно положительного заключения; экономика: NPV, BCR (пороги 1.5/1.0/0.7), LCC по 8 стадиям, сравнение 4 альтернатив (веса → Us). AHP: λmax, CI, CR (RI по таблице Сати).
- Историческая база v15–v17: 31 вопрос, 3 блока (10 + 9 + 12), веса 30/35/35, категории ≥85/≥70/≥50/≥30 — доступны через миграцию и в прежних снимках (versions/…).
- Шкала: 5 / 4 / 3 / 1 / 0 и «Н/П» (вопрос исключается, веса ренормируются); все «Н/П» → «Недостаточно данных».
- I = 100 · ΣBⱼ / ΣWⱼ(применимых), Bⱼ = Wⱼ · Pⱼ, Pⱼ = Σ баллов /(5 · N отв.).
- Категории: ≥85 Высокая · ≥70 Хорошая · ≥50 Удовлетворительная · ≥30 Неудовлетворительная · <30 Критическая.
- Правило: баллы 4–5 — только при документальном подтверждении (показатель K).
- Консенсус респондентов: медиана (или среднее); «Н/П» побеждает, если его больше, чем чисел.
- Прогноз предложений: I' = calcCore(ответы с целевыми баллами); стоимость балла = доп. финансирование / ΔI.
- **Экспертная методика А/Ц:** I_А и I_Ц = ΣBᵢ/(5·n)·100 % по блокам I и III; уровни ≥85/≥70/≥50/≥30/<30 (Высокая…Критическая); рекомендация = ячейка матрицы решений 5×5 (А × Ц); стоп-фактор «ДА» блокирует рекомендацию; перспективы: реалистичная (I_Ц ≥ 70) / условно реалистичная (50–69) / маловероятная (<50 или стоп-фактор).
- Регрессионные якоря v18 (Средний, 30 кодов): все «4» → I = 80.0 «Приемлемый», I_А = I_Ц = I_Р = 80, Coverage 100 ≥ 85; все «5» → 100 «Высокий»; все «1» → 20 «Критический»; «НП» с обоснованием — вне индекса при Coverage 100; «НД» — Coverage 96.7; AHP 2/4/2 → веса 4/7·2/7·1/7, CR = 0; импорт книги № 9 — Средний I_А 98.8 %. Якоря Excel № 9: см. п. 23 журнала VERSIONS.md. Исторические: v15 (31 вопрос) 72.6 (I_А 80.0 / I_Ц 76.7) / 70.4 / 71.7 / 20 и 100 / 74.9; v1–v14 (27 вопросов) 72.9 / 70.4 / 72.0 / 69.1 / 75.7.

## 6. Как начать

1. Откройте `output/Аудит_НИОКР_интерактивная_модель.html` двойным кликом (браузер, офлайн).
2. Первый запуск: «🧭 Тур» (6 шагов по v18.0) или справка «?» (горячие клавиши и роли).
3. Подробный порядок работы — `output/6_Инструкция_пользователя_модели_v17.md`, раздел 1 «Быстрый старт»; методика экспертной оценки — `output/8_Методика_Актуальность_Целесообразность.md`.
4. Перенос данных между машинами: «Экспорт JSON» → «Импорт» (старые файлы мигрируются автоматически, включая перенос ответов 27 → 31).
5. Передача результатов аудита в Word: «🖨 Акт оценки» → «📋 Копировать текст» (акт) и **«⬇ Чек-лист (MD)»** — файл `Чек-лист_НИОКР_<шифр>_31.md` со всеми ответами, индексами I_А/I_Ц и экспертным заключением (новое в v17.0).
