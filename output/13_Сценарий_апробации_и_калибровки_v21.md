# СЦЕНАРИЙ ПИЛОТНОЙ АПРОБАЦИИ И КАЛИБРОВКИ ЭО-НИОКР v2.0

**Пакет v21.1 (этап 21Б). Приложение к методике ЭО-НИОКР v2.0 (разделы 16–20). Рабочий документ комиссии.**

## 1. Цель и рамки

Пилот подтверждает применимость методики на реальных НИОКР организации и даёт основания для двух решений комиссии: (1) калибровка порогов зон и σ (раздел 18 методики, протокол — приложение №11); (2) включение отключаемых расширений v2.0 — дифференцированных весов экспертов и блока результативности Р1–Р6 с индексом I_R (раздел 17). Состав инструментария (22 вопроса, 5 стоп-факторов, 9 «красных» вопросов, шкала и якоря) в ходе пилота **не изменяется**; уточнение формулировок якорей — только по итогам отдельного пересмотра методики.

До завершения пилота расширения v2.0 остаются выключенными: процедура полностью идентична ЭО-НИОКР v1.0. Калибровка без утверждённого протокола не допускается.

## 2. Выборка и учебный стенд

**Реальный пилот:** не менее 5 действующих НИОКР разных стадий и направлений (желательно: 1–2 с завершёнными этапами — для проверки блока Р; 1 с известными проблемами реализации; 1 с признаками утраты актуальности). На каждую НИОКР — от 3 до 10 экспертов; суммарно рекомендуется не менее 9 заполненных анкет (инструменты предупреждают о преждевременности калибровки при меньшей выборке).

**Учебный стенд:** демо-портфель модели («🧪 Демо → Портфель демо: 5 НИОКР») — синтетические данные для обучения комиссии и проверки процедур. Контрольные значения стенда приведены в разделе 6; статистика и предложение порогов на стенде — в разделах 8–9. **Решения о калибровке на синтетических данных не принимаются** — стенд служит только для освоения процедуры.

## 3. Роли

| Роль | Ответственность в пилоте |
| --- | --- |
| Председатель комиссии | состав группы, веса (если режим включён), фиксация раунда 1, ведение заседания, решение комиссии, применение калибровки |
| Секретарь | регистрация и выдача бланков, внесение бумажных анкет, экспорт/импорт, повестка, протоколы, статистика |
| Эксперты (3–10 на НИОКР) | независимое заполнение раунда 1, участие в обсуждении, раунд 2 при желании, особые мнения |
| Руководитель НИОКР | пояснения комиссии; не оценивает и не присутствует при первичном заполнении |
| Второй член комиссии (сверка) | контроль двойного ввода бумажных анкет до расчёта |

## 4. График пилота (5 рабочих дней)

| День | Работа | Результат |
| --- | --- | --- |
| Д1 | Подготовка: выборка НИОКР, состав комиссии, карточки объектов; печать и регистрация бланков (или раздача файлов модели / поанкетных JSON) | бланки зарегистрированы; роли назначены; расширения выключены |
| Д2 | Раунд 1: независимое заполнение анкет (бумага или модель); внесение бумажных анкет секретарём + двойная сверка | первичные оценки внесены; председатель фиксирует раунд 1 |
| Д3 | Заседание по каждой НИОКР: повестка (σ>1,00, стоп-факторы, «красные» сигналы, низкие средние); пояснения руководителя; раунд 2 при желании экспертов | протокол обсуждения; исходные оценки сохранены; дельты раундов зафиксированы |
| Д4 | Авто-заключения, решения комиссии (5 рекомендаций), особые мнения; подписи | подписанные заключения по 5 НИОКР; реестр портфеля заполнен |
| Д5 | Статистика апробации; предложение порогов; обсуждение; протокол калибровки; решение о режимах v2.0 | протокол калибровки (или мотивированный отказ); решение о весах / блоке Р |

## 5. Пошаговая процедура в инструментах

### 5.1. Модель (HTML)
1. Вкладка «Портфель»: «➕ Добавить НИОКР» для каждой НИОКР выборки; карточка объекта на «Дашборде». 2. «Анкеты экспертов»: эксперты заполняют свои слоты (роль «Эксперт» изолирует); бумажные анкеты вносит секретарь. 3. Председатель: «📌 Зафиксировать раунд 1». 4. «Сводная оценка»: повестка обсуждения; заседание; раунд 2. 5. «Заключение и протокол»: решение комиссии, печать/PDF, MD-протокол. 6. «Портфель»: сравнительная матрица, «⬇ Отчёт (MD)» для доклада. 7. «Калибровка»: статистика, «📐 Предложить по данным», «👁 Предпросмотр влияния», решение комиссии, «✅ Применить ко всему портфелю» с основанием и № протокола (или «↺ Значения по умолчанию»).

### 5.2. Excel
Листы Э1–Э10 — анкеты (валидации 1–5/Н/О); «Свод» — расчётное ядро; «Панель» — визуализация; «Заключение» — авто-текст и поля протокола; «Портфель» — реестр (перенос значений из строки-помощника 45 после оценки каждой НИОКР); «Калибровка» — пороги B4:B8, режимы B9/B10, статистика, поля протокола; «Анкета_бланк» — печать приложения №1 (А4).

## 7. Критерии успешной апробации (методика §16.3)

| Проверяемое | Критерий pass | Действие при fail |
| --- | --- | --- |
| Различение ситуаций | «актуальная, но нереализуемая» и «реализуемая, но устаревшая» дают зеркальные зоны (В/Н против Н/В) | проверить якоря А1/А6/А8, Ц1/Ц2/Ц4 |
| Согласованность | σ ≤ 0,80 не менее чем по 18 из 22 вопросов в каждой ситуации | переписать якорь вопроса с σ>1,00 (без изменения состава) |
| Н/О | доля Н/О ≤ 15 % по всем оценкам | пересмотреть формулировку «некомпетентного» вопроса |
| Время | заполнение 22 вопросов ≤ 25 мин на НИОКР | упростить формулировки; комментарий опционален |
| Стоп-факторы | в ситуации утраты актуальности хотя бы один эксперт отмечает СФ | уточнить формулировку СФ |
| «Красные» вопросы | сигналы срабатывают у ≥2 экспертов в ожидаемых ситуациях | пересмотреть вопрос как сигнал |
| Процедура | двойная сверка бумажных анкет выполнена до расчёта; раунд 1 зафиксирован | повторить внесение; восстановить независимость процедуры |

## 8. Статистика апробации на учебном стенде (пример)

Снято с демо-портфеля модели (вкладка «Калибровка»; файл данных scripts/data/demo_stats_v21.json):

- НИОКР: **5**; заполненных анкет: **16**; числовых оценок: **352**; отметок Н/О: **0**.
- Средний балл: **3.31**; медиана: **4**; σ баллов (популяционное): **1.16**.
- Доля баллов 1–2: **27.0 %**; доля 3: **22.7 %**; доля 4–5: **50.3 %**.

| Балл | Частота | Доля |
| --- | --- | --- |
| 1 | 26 | 7.4 % |
| 2 | 69 | 19.6 % |
| 3 | 80 | 22.7 % |
| 4 | 124 | 35.2 % |
| 5 | 53 | 15.1 % |

На реальном пилоте таблица заполняется по фактическим анкетам; дополнительно анализируются распределения групповых индексов I_A/I_C (и I_R при включённом блоке Р) и повопросных σ — именно они питают предложение порогов.

## 9. Предложение порогов на стенде и его анализ

Инструмент («📐 Предложить по данным») на стенде предлагает:

| Параметр | Базовое (v1.0) | Предложение на стенде |
| --- | --- | --- |
| Порог зоны В | 4,00 | 4.10 |
| Порог зоны С | 3,00 | 3.10 |
| σ1 (высокая согласованность) | 0,50 | 0.30 |
| σ2 (приемлемая) | 0,80 | 0.45 |
| σ3 (флаг разногласия) | 1,00 | 0.50 |

**Анализ (пример критического рассмотрения предложения):**
- Зоны: при порогах 4.10/3.10 все 5 НИОКР стенда сохраняют свои зоны и рекомендации — предложение не меняет ни одного решения. Оснований для изменения зон на такой выборке недостаточно.
- σ: предложение 0.30/0.45/0.50 существенно жёстче базового, поскольку синтетические эксперты стенда демонстрируют искусственно высокую согласованность. Перенос этих границ на реальные оценки приведёт к массовым ложным флагам «РАЗНОГЛАСИЕ» и перегрузке повестки.
- Вывод: предложение носит рекомендательный характер (раздел 18.3 методики); на учебной выборке калибровка **не применяется**. На реальном пилоте расчёт повторяется по фактическим данным; комиссия вправе принять предложение полностью, частично или отклонить с обоснованием.

## 11. Решение о расширениях после реального пилота

| Расширение | Основания для включения | Решение комиссии |
| --- | --- | --- |
| Веса экспертов | документированная асимметрия компетенций по тематике НИОКР; веса назначены до раунда 1; основание в протоколе | Да / Нет / отложить |
| Блок Р и I_R | в выборке ≥3 НИОКР с завершёнными этапами; эксперты понимают якоря Р; доля Н/О по блоку ≤ 1 на анкету | Да / Нет / отложить |
| Калибровка порогов | реальная выборка ≥5 НИОКР / ≥9 анкет; статистика устойчива; предложение обосновано | принять / частично / отклонить |

Любое включение фиксируется в протоколе; пороги и режимы применяются ко всему портфелю. Повторный пересмотр — не чаще раза в квартал либо по накоплении ≥5 новых НИОКР (раздел 18.6).

## 12. Риски и типовые ошибки пилота

- Подгонка порогов под желаемый результат по конкретной НИОКР — запрещена; пороги выбираются по распределению всей выборки.
- Калибровка без протокола или на синтетических данных — не допускается.
- Изменение весов после фиксации раунда 1 — не допускается (подгонка результата).
- Трактовка Н/О как 3 — запрещена; Н/О исключается из знаменателя.
- Сравнение НИОКР, оценённых при разных порогах, без оговорки — некорректно (раздел 19.4).
- Внесение бумажных анкет без двойной сверки; исправления на бланке без подписи эксперта.
- Присутствие руководителя НИОКР при первичном заполнении; раскрытие оценок коллегам до завершения раунда 1.
