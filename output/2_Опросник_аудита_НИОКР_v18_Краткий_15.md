# ОПРОСНИК АУДИТА НИОКР v18.0 — КРАТКИЙ (15 кодов)

**Рабочий документ первичной (экспресс) оценки.** Методика — «Научно» (этап 18): трёхуровневая система опросников **Краткий (15)** / Средний (30) / Полный (60). Настоящий документ — screening-инструмент: быстрая проверка обоснованности НИОКР без углублённого аудита. Кодовая сетка **А1–А5 · Б6–Б10 · В11–В15** по трём направлениям: **актуальность (I_А), целесообразность (I_Ц), результативность (I_Р)**; все веса вопросов равны 1. Автономный расчёт — лист «Краткий_15» файла `9_Калькулятор_аудита_НИОКР_v2.xlsx` и интерактивная модель `Аудит_НИОКР_интерактивная_модель.html` (v18.0); расчётный шаблон уровня — `1_Шаблон_расчёта_аудита_НИОКР_v18_Краткий_15.xlsx`.

**Назначение уровня:** выявить существенные сомнения в обоснованности НИОКР и определить маршрутизацию: продолжить в текущем контроле, направить на средний опросник или инициировать внеплановое углублённое обследование. Итоги Краткого уровня — **предварительные**: безусловные категории I–IV по ним не выносятся.

## 1. Шкала ответов и специальные статусы

| Балл | Название | Содержание |
| --- | --- | --- |
| **5** | Отлично | Полное соответствие, подтверждённое доказательствами |
| **4** | Хорошо | Основные требования выполнены, замечания несущественны |
| **3** | Удовлетворительно | Выполнено частично, имеются устранимые недостатки |
| **2** | Неудовлетворительно | Значительные отклонения, требуется пересмотр |
| **1** | Критически низко | Требование практически не выполнено |
| **0** | Не выполнено | Отсутствует результат или требование опровергнуто |
| **НД** | Нет данных | Нельзя достоверно оценить |
| **НП** | Неприменимо | Исключается из расчёта с обоснованием |

Правила уровня «Краткий»:
1. **«НД» (нет данных)** — остаётся в знаменателе Coverage, но не даёт числителя; снижает покрытие, индексы не трогает.
2. **«НП» (неприменимо)** — исключает вопрос из индекса **и** из Coverage; **обязательно письменное обоснование**, иначе фиксируется контрольное замечание.
3. **Баллы 4–5** засчитываются только при наличии доказательства (документ или ссылка в поле «Доказательство»); иначе — контрольное замечание «4–5 без доказательства».
4. **Баллы 0–2** требуют письменного обоснования и включают обязательные действия подтверждения (раздел 8).
5. **Принцип консерватизма**: при ситуации «между якорями» выбирается меньший балл.
6. **Coverage** = доля вопросов с содержательным ответом; **порог уровня — 80 %**. Ниже порога положительное заключение не выносится независимо от индексов.

## 2. Формулы

- Индекс направления: **I_k = Σ(wᵢ·xᵢ) / (5·Σwᵢ) · 100 %** — сумма по кодам направления с числовыми ответами (все веса равны 1).
- Направления: **I_А** — коды А1–А5, **I_Ц** — коды Б6–Б10, **I_Р** — коды В11–В15.
- Комплексный индекс **I = ∛(I_А·I_Ц·I_Р)** — справочное число; маршрутизация принимается по паре I_А × I_Ц в матрице (раздел 6) и по формулировкам заключения (раздел 9).
- **Coverage = (число кодов с ответом 0–5) / (15 − число «НП») · 100 %** («НД» и пропуски снижают покрытие).

### Уровни индексов (общие для методики; применяются и в матрице решений)

| Уровень | Диапазон | Рекомендуемое действие |
| --- | --- | --- |
| **Высокий** | 85–100 % | Продолжить без существенной корректировки |
| **Приемлемый** | 70–84 % | Продолжить с корректирующими мероприятиями |
| **Проблемный** | 55–69 % | Разработать план восстановления и провести контроль |
| **Критический** | Менее 55 % | Рассмотреть изменение концепции, объёма или альтернативу |

### Полосы обоснованности уровня «Краткий» (маршрутизация)

| Диапазон | Уровень | Действия комиссии |
| --- | --- | --- |
| 80–100% | Высокий | Продолжить выполнение в рамках текущего контроля |
| 60–79% | Приемлемый | Продолжить, определить замечания и сроки их устранения |
| 40–59% | Низкий | Направить на средний опросник |
| 0–39% | Критически низкий | Провести внеплановое углублённое обследование |

## 4. Стоп-факторы

Проверяются по формам «да/нет/не проверяли» до подведения итогов. Подтверждение стоп-фактора переводит заключение в эскалацию независимо от индексов.

| № | Стоп-фактор |
| --- | --- |
| 1 | разработка фактически дублирует уже имеющееся решение, а различия не обоснованы |
| 2 | ключевые технические характеристики не могут быть достигнуты в пределах принятой концепции |
| 3 | конечный потребитель отказался от результата и отсутствуют другие обоснованные потребители |
| 4 | выявлены существенные нарушения, влияющие на достоверность представленных результатов |
| 5 | отсутствует реальная возможность завершения проекта в допустимые сроки и с приемлемыми ресурсами |

## 5. Зрелость результата M0–M9

| M | Стадия | Признак готовности |
| --- | --- | --- |
| **M0** | Идея | Проблема и предполагаемый способ решения сформулированы |
| **M1** | Исследовательская проработка | Проведены исследования, выявлены ключевые ограничения |
| **M2** | Концепция | Сформирована техническая концепция и проведено моделирование |
| **M3** | Экспериментальное подтверждение | Проверены основные технические принципы |
| **M4** | Макет / лабораторный образец | Подтверждены основные функции и характеристики |
| **M5** | Опытный образец | Изготовлен и испытан образец |
| **M6** | Завершение испытаний | Подтверждены заданные характеристики, замечания обработаны |

Контрольное правило: заявлен уровень **M≥5**, а испытаний/подтверждений нет — фиксируется замечание «M≥5 без подтверждения» (в расчётном шаблоне — ячейка листа «Расчёт»).

## 11. Экономика (справочно)

## 15. Приложение В. Принципы аудита

| Принцип | Содержание |
| --- | --- |
| **Независимость** | Эксперт не должен оценивать собственную работу или результаты, за которые непосредственно отвечает |
| **Объективность** | Оценки основываются на проверяемых фактах |
| **Компетентность** | Каждый вопрос оценивается специалистом соответствующего профиля |
| **Доказательность** | Балл должен иметь документальное или иное проверяемое обоснование |
| **Коллегиальность** | Итоговое заключение принимается с учётом мнений членов комиссии |
| **Персональная ответственность** | Каждый эксперт отвечает за обоснованность своей оценки |
| **Конфиденциальность** | Информация используется в пределах предоставленных полномочий |
| **Прослеживаемость** | Должна сохраняться история оценок, изменений и решений |

## 16. Приложение Г. Место уровня «Краткий» в системе 15/30/60

| Ситуация | Переход |
| --- | --- |
| I_А или I_Ц в полосе 40–59 % | направить на опросник «Средний (30)» — раздел «Полосы обоснованности» |
| I_А или I_Ц ниже 40 % | внеплановое углублённое обследование (уровень «Полный (60)») |
| Один «НД» и более при Coverage < 80 % | сбор документов и повторный Краткий прогон |
| Подтверждённый стоп-фактор | эскалация заказчику без перехода по уровням |

Ответы прежних бумажных редакций (27 и 31 вопрос) мигрируют в модель в кодовую сетку «Средний»; уровень «Краткий» заполняется самостоятельно как первичный screening.
