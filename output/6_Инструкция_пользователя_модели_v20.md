# ИНСТРУКЦИЯ ПОЛЬЗОВАТЕЛЯ — интерактивная модель ЭО-НИОКР v20.0

**Файл:** `output/Аудит_НИОКР_интерактивная_модель.html` (автономный HTML, снимок `output/versions/Аудит_НИОКР_модель_v20.0.html`). Откройте двойным кликом — работает офлайн в любом современном браузере, установка не требуется.

Модель реализует **Методику экспертной оценки актуальности и целесообразности НИОКР (ЭО-НИОКР v1.0, ред. 20)**: ровно 22 основных вопроса (10 актуальность + 12 целесообразность), единая шкала 1–5 с отметкой Н/О, 5 стоп-факторов, 9 «красных» вопросов, два индекса I_A и I_C, матрица решений 3×3 с оверрайдом стоп-фактора, σ-согласованность мнений. **Экспертная группа — до 10 человек** (минимум 3 рекомендуемых). Документальное подтверждение баллов не требуется.

**Новое в v20.0:** слоты Э1–Э10; роли «Председатель / Секретарь / Эксперт» с изоляцией эксперта; раунды оценки (фиксация раунда 1, правки после обсуждения хранятся как раунд 2, исходные не затираются); поанкетный экспорт/импорт JSON для распределённого слепого заполнения; автоматическая «Повестка обсуждения комиссии»; протокол в Markdown; демо-набор «10 экспертов: разброс мнений»; автоматическая миграция сохранений v19 (5 экспертов → 10).

## 1. Быстрый старт

1. Откройте файл. Вкладка **«📊 Дашборд»** — заполните карточку объекта (наименование, шифр, исполнитель, заказчик, дата).
2. Вкладка **«🧮 Анкеты экспертов»** — выберите эксперта Э1…Э10 (чипы сверху), укажите Ф.И.О., компетенцию, дату. Каждый эксперт заполняет **свою** анкету изолированно; пустые слоты в расчёте не участвуют.
3. По каждому из 22 вопросов нажмите балл 1–5 или «Н/О» (повторный клик снимает ответ). Разверните «якоря шкалы 1–5» под вопросом, если нужна опора; «разграничение» — для близких пар вопросов.
4. Заполните блоки **«Стоп-факторы»** (Да / Нет / Неопределённо) и **«Красные вопросы»** (1–5: 1=Да … 5=Нет).
5. Индивидуальные индексы I_A/I_C эксперта считаются сразу под разделами (с правилом минимальной полноты: ≤2 Н/О на направление).
6. **«📋 Сводная оценка»** и **«📈 Панель»** — групповые индексы, σ, повопросная статистика по 10 колонкам экспертов (среднее/min/max/разброс/σ/флаги), групповые сигналы СФ и КВ, **повестка обсуждения**, матрица с активной ячейкой, графики.
7. **«📄 Заключение и протокол»** — автоматический текст заключения из 9 разделов + протокол комиссии (рекомендация из 5 вариантов, обоснование, особые мнения, подписи). Кнопки: печать/PDF, копирование в Word, выгрузка чек-листа и **протокола** в Markdown.
8. **«📚 Методика»** — операционный справочник: шкала, правила, якоря 1–5 по всем 22 вопросам, СФ/КВ, регламент, периодичность, апробация. Есть поиск по разделу.

## 2. Роли (переключатель в шапке)

| Роль | Что видит и делает |
| --- | --- |
| **Председатель** | всё; фиксирует раунд 1; заполняет решение комиссии |
| **Секретарь** | анкеты, свод, панель, экспорт/импорт; поля решения комиссии заблокированы; баллы экспертов не изменяет |
| **Эксперт** | только **своя** анкета (выбор в соседнем списке) и методика; свод, дашборд, панель и заключение закрыты до открытия председателем — так обеспечивается независимость первичной оценки |

Передайте эксперту файл модели: он выберет роль «Эксперт» и свой слот. Для удалённой работы используйте **поанкетный обмен**: «⬇ Анкета Эk (JSON)» → эксперт заполняет и возвращает файл → «⬆ Импорт анкеты в Эk» (или `niokrAPI.importExpert(json, slot)`).

## 3. Раунды оценки

1. **Раунд 1** — первичное независимое заполнение. После его завершения председатель нажимает **«📌 Зафиксировать раунд 1»** в анкете эксперта (у чипа появляется бейдж R2-готовности).
2. **Раунд 2** — после обсуждения расхождений эксперт вправе поменять баллы; первоначальные оценки хранятся отдельно и не затираются.
3. В своде появляются колонки «I_A/I_C раунд 1», в заключении и протоколе — строка «Повторная оценка после обсуждения: Эk: I_A 3.20 → 3.60 …». Расчёт выполняется по действующим оценкам.
4. **«✖ Сбросить фиксацию»** — отменяет фиксацию раунда (текущие ответы остаются).

## 4. Правила расчёта (памятка)

| Что | Правило |
| --- | --- |
| I_A эксперта | ΣA_i / N_A по 10 вопросам; Н/О исключены из знаменателя; минимум 8 оценённых, иначе «НЕ РАССЧИТАН» |
| I_C эксперта | ΣC_j / N_C по 12 вопросам; минимум 10 оценённых |
| Групповые I_A, I_C | простое среднее индивидуальных индексов экспертов с действующей оценкой (веса равные; пустые анкеты игнорируются) |
| Состав группы | от 3 до 10 экспертов; при <3 заполненных анкет модель выдаёт предупреждение о предварительном характере заключения |
| Зоны | В 4,00–5,00 · С 3,00–3,99 · Н 1,00–2,99 |
| σ | популяционное стандартное отклонение; ≤0,50 высокая · ≤0,80 приемлемая · ≤1,00 умеренные · >1,00 существенные разногласия (обсуждение, исходные оценки сохраняются) |
| Повопросные флаги | σ>1,00 → «РАЗНОГЛАСИЕ»; среднее ≤2 → «НИЗКАЯ» |
| Стоп-факторы | «Да» хотя бы у одного эксперта → ВЫЯВЛЕН: рекомендация «Продолжить НИОКР» автоматически понижается до «Пересмотреть параметры НИОКР (стоп-фактор)»; «Неопределённо» без «Да» → НЕОПРЕДЕЛЁН |
| «Красные» сигналы | негативные (КВ1–6, 9): балл 1–2; позитивные (КВ7–8): балл 4–5; групповой сигнал при ≥2 экспертах (порог не зависит от размера группы); единичный — особое мнение |
| Матрица | 3×3 по зонам (I_A ↓ × I_C →); при отсутствии одного из индексов рекомендация не формируется |

## 5. Сервисные функции

- **⬇ JSON / ⬆ JSON** — экспорт и импорт общего состояния (форматы v19 и v20; v19 автоматически мигрирует в 10 слотов); **Ctrl+S** — быстрый экспорт.
- **⬇ Анкета Эk / ⬆ Импорт анкеты** — поанкетный обмен для распределённого слепого заполнения (см. раздел 2).
- **🖨 Печать** — печатает активную вкладку (заключение/протокол — для PDF и подписей; анкета эксперта — для бумажной процедуры).
- **☾** — тёмная тема; **?** — справка; **🧪 Демо** — контрольные ситуации С-1/С-2/С-3, набор **«10 экспертов: разброс мнений»** (I_A=2,99, σ(I_A)≈0,08, групповой сигнал КВ3 → матрица Н/В) и полная очистка.
- Автосохранение в localStorage браузера (переживает перезагрузку страницы; ключ `niokr20_state`).
- Горячие клавиши: **1–6** вкладки, **t** тема, **d** демо, **?** справка, **Esc** закрыть окно.
- **Экспорт CSV** на вкладке «Свод» (10 колонок экспертов); **⬇ Чек-лист (MD)** и **⬇ Протокол (MD)** на вкладке «Заключение».
- **Повестка обсуждения комиссии** (вкладка «Свод») формируется автоматически: вопросы с σ>1,00 (с оценками экспертов), выявленные/неопределённые стоп-факторы, групповые и единичные «красные» сигналы, средние ≤2.

## 6. Дисциплина процедуры

- Эксперт не показывает анкету коллегам до завершения раунда 1; роль «Эксперт» в модели обеспечивает это технически.
- Секретарь не изменяет баллы и не трактует Н/О как 3.
- Председатель не имеет приоритетного голоса: его балл весит как любой другой.
- Руководитель НИОКР приглашается для пояснений, но не оценивает и не присутствует при первичном заполнении.
- Комиссия не обязана приходить к единому мнению; разногласие фиксируется как результат (особое мнение — в протокол).

## 7. Апробация (пилот)

Кнопка «🧪 Демо» заполняет контрольные ситуации: С-1 «актуальная, но нереализуемая» (ожидается В/Н → «Пересмотреть содержание и способ реализации»), С-2 «реализуемая, но устаревшая» (Н/В → «Пересмотреть необходимость и назначение работ» + СФ1), С-3 «перспективная, но без потребителя» (С/С → «Пересмотреть параметры НИОКР» + КВ7/КВ8), **«10 экспертов: разброс мнений»** (проверка группового расчёта на 10 анкетах). Сравните фактический результат с ожидаемым; вопросы с σ>1,00 — кандидаты на переписывание якорей (состав 22 вопросов не меняется).

## 8. Частые вопросы

- **Почему нет общего балла?** Единый балл скрывает принципиальные проблемы (высокая актуальность компенсирует нулевую целесообразность). Решение — по паре индексов.
- **Когда ставить Н/О, а когда 3?** Н/О — «я не компетентен» (о эксперте); 3 — «признак промежуточный, обстоятельства сопоставимы» (о НИОКР).
- **Насколько увеличивать группу?** 3–5 экспертов достаточно для типовой НИОКР; до 10 — при междисциплинарных работах, когда нужны все пять компетенций с дублированием (по 2 эксперта на направление). Порог группового «красного» сигнала (≥2) не меняется.
- **Переносятся ли данные v19?** Да: сохранения v19 (5 экспертов) автоматически мигрируют в 10 слотов при первом открытии; импорт JSON v19 также поддерживается. Данные v18 и старше (15/30/60 вопросов) не переносятся — это методический перезапуск.
- **Эксперт поставил 1 или 5 без комментария?** Блокировки нет: комментарий рекомендован, но не обязателен (методика экспертная, не документарная).
