# ЧЕК-ЛИСТ АУДИТА НИОКР

## Аудит актуальности, эффективности и целесообразности НИОКР

**Финальная версия 2.0** (математически выверенная, с добавленными вопросами)

**Объект аудита:** отдельная НИОКР, этап НИОКР или завершённая разработка.

**Цель:** определить фактическую научно-техническую ценность результата, обоснованность понесённых затрат, перспективы внедрения и необходимость продолжения финансирования.

**Что изменено в финальной версии по сравнению с исходным проектом:**

1. В каждый из трёх блоков добавлено по 3 вопроса (отмечены ★): включены вопросы комиссии из стандарта презентации «Паспорт текущего состояния НИОКР» (слайды 2, 4, 7, 8) и дополнительные вопросы, предложенные по итогам обсуждения. Итого 27 вопросов: 3 блока × 9 вопросов.
2. Устранена математическая несогласованность: в исходной редакции смешивались «сырые» баллы блоков (сумма баллов за ответы) и их взвешенный вклад (0–30 / 0–35 / 0–35). В финальной версии введены раздельные обозначения Sⱼ (сырой балл), Pⱼ (процент выполнения), Bⱼ (взвешенный балл).
3. Правило обработки «Н/П» доведено до полной математической корректности: исключение из числителя и знаменателя на уровне вопроса, ренормировка весов на уровне блока, определённое поведение в случае, когда «Н/П» даны все вопросы.
4. Заполнены пропущенные наименования оценок в итоговой шкале (Высокая / Хорошая / Удовлетворительная / Неудовлетворительная / Критическая).
5. Добавлены числовые примеры расчёта, включая пример с ренормировкой.

## 1. Методика оценки и правила заполнения

Каждый вопрос предполагает ответ аудитора, документальное подтверждение и балльную оценку.

| Ответ | Балл | Интерпретация |
| --- | --- | --- |
| Да, полностью | 5 | Требование выполнено, подтверждено документами |
| В основном да | 4 | Незначительные недостатки |
| Частично | 3 | Выполнено не в полном объёме |
| Скорее нет | 1 | Существенные недостатки |
| Нет | 0 | Не выполнено либо отсутствует подтверждение |
| Не применимо | Н/П | Исключается из расчёта с обязательным обоснованием |

Шкала намеренно дискретна: промежуточное значение «2 балла» не используется, чтобы исключить «усреднённые» оценки без содержательной позиции аудитора. Каждый балл имеет словесный якорь (см. шкалы интерпретации в блоках).

**Правило документального подтверждения.** Отсутствие документального подтверждения не позволяет присваивать 4 или 5 баллов только на основании устных пояснений исполнителя. В электронном шаблоне это правило контролируется автоматически: при высоком балле без подтверждения вопрос помечается предупреждением.

**Правило работы с «Н/П».** Ответ «Н/П» допускается, только если вопрос объективно неприменим к объекту аудита (например, «Обоснована ли оставшаяся потребность в финансировании?» для завершённой и закрытой финансированием НИОКР). Обоснование «Н/П» указывается в комментарии аудитора обязательно. Вопрос с ответом «Н/П» исключается одновременно из числителя и из знаменателя расчёта блока (см. раздел 5). «Н/П» не может использоваться как способ ухода от негативной оценки: при спорной трактовке вопрос считается применимым.

## 5. Матодика расчёта интегрального показателя (математически выверенная)

### 5.1. Обозначения

- j ∈ {I, II, III} — номер блока; W = (W₁, W₂, W₃) = (30, 35, 35) — веса блоков, ΣWⱼ = 100.
- Bᵢⱼ — балл i-го вопроса блока j: Bᵢⱼ ∈ {0, 1, 3, 4, 5} либо «Н/П».
- Nⱼ — число применимых вопросов блока j (ответы «Н/П» не учитываются): 0 ≤ Nⱼ ≤ 9.
- Sⱼ — сумма баллов применимых вопросов блока j: Sⱼ = Σ Bᵢⱼ (по применимым вопросам), 0 ≤ Sⱼ ≤ 5·Nⱼ.

### 5.2. Порядок расчёта

**Шаг 1. Процент выполнения блока:**

```
Pⱼ = Sⱼ / (5 · Nⱼ),   при Nⱼ > 0;      0 ≤ Pⱼ ≤ 1
```

**Шаг 2. Взвешенный балл блока:**

```
Bⱼ = Wⱼ · Pⱼ          0 ≤ Bⱼ ≤ Wⱼ  (т.е. 0–30 / 0–35 / 0–35)
```

**Шаг 3. Интегральный показатель (общая форма с обработкой «Н/П»):**

```
        Σ (Wⱼ · Pⱼ)  по блокам с Nⱼ > 0
I = 100 · ────────────────────────────────
        Σ Wⱼ         по блокам с Nⱼ > 0
```

Если хотя бы один вопрос в каждом блоке применим (обычный случай, Nⱼ > 0 для всех j), знаменатель равен 100 и формула вырождается в:

```
I = B₁ + B₂ + B₃ = 30·P₁ + 35·P₂ + 35·P₃        0 ≤ I ≤ 100
```

**Граничные случаи:**

- Блок целиком получил «Н/П» (Nⱼ = 0): блок исключается из расчёта, его вес перераспределяется пропорционально на оставшиеся блоки (это и есть ренормировка в общей формуле шага 3).
- Все 27 вопросов получили «Н/П»: интегральный показатель не рассчитывается, выводится «Недостаточно данных»; комиссия обязана либо собрать данные, либо принять решение на основании контрольных условий (раздел 8).

**Связь с исходной редакцией.** Формула исходного проекта I = 30·S₁/30 + 35·S₂/30 + 35·S₃/30 была записана для блоков по 6 вопросов (максимум «сырого» балла 30) и не определяла поведение при полностью неприменимом блоке. Финальная формула эквивалентна ей по смыслу (нормирование сырого балла на фактический максимум блока), но корректна для любого числа применимых вопросов и любого числа блоков.

### 5.3. Пример расчёта 1 (базовый случай)

| Блок | Ответы аудитора | Sⱼ | Nⱼ | Pⱼ | Bⱼ |
| --- | --- | --- | --- | --- | --- |
| I. Актуальность (W=30) | 5, 4, 4, 3, 5, 4, Н/П, 3, 4 | 32 | 8 | 32/40 = 0,800 | 24,00 |
| II. Эффективность (W=35) | 4, 3, 3, 4, 3, 3, 4, 3, 1 | 28 | 9 | 28/45 ≈ 0,622 | 21,78 |
| III. Целесообразность (W=35) | 5, 4, 4, 3, 4, 4, 3, 4, Н/П | 31 | 8 | 31/40 = 0,775 | 27,13 |

I = 24,00 + 21,78 + 27,13 = **72,9 балла** → оценка «Хорошая» (70–84) → решение: продолжить с устранением выявленных недостатков.

### 5.4. Пример расчёта 2 (блок целиком «Н/П» — ренормировка)

Пусть в том же примере все 9 вопросов блока III оказались неприменимы (например, НИОКР завершена и передана заказчику — вопросы о дальнейших вложениях потеряли смысл):

- B₁ = 24,00; B₂ = 21,78; B₃ — не рассчитывается (N₃ = 0).
- I = 100 · (24,00 + 21,78) / (30 + 35) = 4578 / 65 = **70,4 балла** → «Хорошая».

Обратите внимание: без ренормировки (простое обнуление B₃) оценка составила бы 45,8 балла («Неудовлетворительная») — то есть математически неверный результат: наказание за неприменимость вопросов вместо оценки по существу. Ренормировка устраняет это искажение.

## 7. Контрольные условия, влияющие на итоговое решение

Независимо от набранных баллов комиссия должна отдельно проверить следующие обстоятельства. Любое выявленное условие требует индивидуального рассмотрения и фиксируется в акте.

| № | Контрольное условие | Последствие |
| --- | --- | --- |
| 1 | Утрачена потребность государственного или корпоративного заказчика | Обязательное рассмотрение целесообразности продолжения |
| 2 | Выявлено дублирование другой НИОКР | Проверка возможности объединения работ |
| 3 | Подтверждена техническая невозможность достижения заданных характеристик | Рассмотрение прекращения или изменения ТЗ |
| 4 | Выявлены существенные нарушения требований безопасности | Приостановка соответствующих работ до устранения |
| 5 | Отсутствует подтверждение существенной части понесённых затрат | Дополнительная финансовая проверка |
| 6 | Результат имеет стратегическое значение для организации или государства | Отдельная экспертная оценка стратегической ценности |
| 7 | Результат готов к внедрению, но не используется | Проверка причин отсутствия внедрения и ответственности |

### Выводная часть (обязательная)

В заключении комиссия должна ответить на пять главных вопросов:

1. **Ценность:** представляет ли НИОКР научно-техническую, технологическую или стратегическую ценность для организации?
2. **Результативность:** соответствует ли полученный результат вложенным ресурсам и первоначальным целям?
3. **Востребованность:** существует ли реальная потребность в результате сейчас и в перспективе?
4. **Перспективы:** целесообразно ли продолжать финансирование, внедрять или модернизировать разработку?
5. **Ответственность:** кто, в какие сроки и за счёт каких ресурсов должен обеспечить реализацию принятого решения?

**Пример формулировки итогового заключения:**

> По результатам аудита установлено, что НИОКР сохраняет актуальность и научно-техническую ценность. Полученные результаты в основном соответствуют установленным требованиям. Вместе с тем выявлены недостатки в части практического внедрения, подтверждения экономической эффективности и определения потребности конечного заказчика. Интегральная оценка составляет 72,9 балла из 100 (оценка «Хорошая»); вопрос 7 блока I исключён из расчёта как неприменимый. Комиссия считает целесообразным продолжить работы с корректировкой технического задания, уточнением сроков и бюджета, а также разработкой плана внедрения результата с измеримыми показателями. Ответственным подразделениям установить контрольные сроки выполнения мероприятий.

## 9. Применение чек-листа в общей системе аудита НИОКР

Чек-лист является инструментом **Уровня 3** трёхуровневой системы проверки:

- **Уровень 1. Документальный аудит** — проверка ТЗ, договоров, актов, отчётов, РКД, результатов испытаний, интеллектуальной собственности и исполнения обязательств.
- **Уровень 2. Финансово-учётный аудит** — проверка стоимости, фактических затрат, раздельного учёта, оборудования, материальных ресурсов, незавершённых работ и активов.
- **Уровень 3. Аудит ценности и перспектив НИОКР (данный чек-лист)** — проверка актуальности, эффективности, научно-технической ценности, востребованности, перспектив внедрения и целесообразности дальнейших вложений.
- **ИТОГ: портфельная карта НИОКР организации** — распределение разработок по категориям: продолжить, внедрить, модернизировать, объединить, приостановить, прекратить.

При аудите большого количества НИОКР результаты каждой разработки сводятся в электронную матрицу портфеля (шифр, стоимость, готовность, интегральный балл, категория риска, управленческое решение) — лист «Портфель» электронного шаблона. Материалы к заседанию комиссии оформляются по стандарту презентации «Паспорт текущего состояния НИОКР» (11 слайдов); сквозная нумерация вопросов чек-листа используется в слайдах интегральной оценки.
