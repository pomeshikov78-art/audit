# ПРОЕКТ СЛАЙДОВ «ТЕКУЩЕЕ СОСТОЯНИЕ НИОКР»

## Покадровый план презентации для проведения оценки по чек-листу аудита

**Назначение:** единая презентационная форма «Паспорт текущего состояния НИОКР» для представления структурными подразделениями на заседании аудиторской комиссии. Соответствует файлу `4_Проект_слайдов_Текущее_состояние_НИОКР.pptx` (14 слайдов: титульный + правила + стандартные слайды 1–11 + регламент).

**Главная задача презентации** — не доложить, что выполняется по каждой НИОКР, а дать комиссии возможность за 10–15 минут получить объективную картину:

- Что разрабатывается и зачем?
- На каком этапе фактически находится работа?
- Что уже сделано и что подтверждено документально?
- Сколько средств израсходовано и сколько ещё потребуется?
- Какие проблемы препятствуют завершению?
- Насколько результат соответствует первоначальным требованиям?
- Нужна ли эта разработка организации сегодня?
- Что необходимо предпринять: продолжить, скорректировать, внедрить или прекратить?

**Общие требования к оформлению:** формат 16:9; один слайд — одна управленческая задача; минимум сплошного текста, максимум таблиц, диаграмм и фактических показателей; красный — критические проблемы, жёлтый — отклонения, зелёный — выполненные показатели; все количественные показатели сопровождаются датой актуальности и источником подтверждения; для каждого вывода указывается документальное основание; жёлтые ячейки таблиц — поля для заполнения.

**Три независимые позиции на каждом слайде:** данные исполнителя (руководитель НИОКР) • оценка подразделения (руководитель подразделения) • оценка аудитора (комиссия, баллы чек-листа).

**Таблица показателей, млн ₽:** первоначальная стоимость; уточнённая стоимость; фактические затраты; оплачено заказчиком; дебиторская задолженность; кредиторская задолженность; стоимость незавершённых работ; остаток финансирования; прогноз затрат до завершения; прогнозная итоговая стоимость; отклонение от бюджета, %; не использовано закупок (остатки).

**Визуальные элементы (справа):** диаграмма «План / Факт / Прогноз» (три полосы); структура затрат (ЗП, материалы, комплектующие, оборудование, услуги соисполнителей, накладные — доли, %); динамика расходов по годам.

**Жёлтая лента — вопросы комиссии (блок II, вопросы 12, 13, 16 ★, 17 ★, 18 ★):**

## Слайд 10. Предложения структурного подразделения и управленческое решение

**Назначение:** получить от руководителя подразделения конкретные предложения о дальнейшей судьбе НИОКР.

**Таблица вариантов решения (столбец «Отметка» — ☐/☑):**

| Вариант решения | Обоснование | Необходимые действия |
| --- | --- | --- |
| Продолжить | сохраняется актуальность | выполнение по действующему плану |
| Продолжить с корректировкой | есть устранимые проблемы | изменение ТЗ, сроков, бюджета |
| Завершить и внедрить | результат готов | передача потребителю |
| Модернизировать | требуется развитие результата | новая редакция ТЗ |
| Объединить | есть дублирование | консолидация разработок |
| Приостановить | не устранены критические проблемы | план устранения замечаний |
| Прекратить | отсутствует целесообразность | оформление прекращения работ |
| Списать | результат утратил ценность | отдельная процедура оценки и списания |

**Панель «Предложения руководителя подразделения» (6 вопросов с полями для ответов):**

1. Какое решение предлагается?
2. Почему именно это решение?
3. Сколько средств необходимо дополнительно?
4. Какие сроки требуются?
5. Кто персонально отвечает за результат?
6. Какой конечный результат получит организация?

**Правило (лента):** предложение подразделения не является решением — комиссия сопоставляет его с баллами чек-листа, контрольными условиями и данными финансового аудита; расхождение обязательно разбирается на заседании.

## Слайд 11. Сводное состояние портфеля НИОКР подразделения

**Обязательный для руководителя подразделения.** Комиссия оценивает не только каждую отдельную НИОКР, но и качество управления всем портфелем разработок.

**1. Общие количественные показатели:** всего НИОКР в портфеле; выполняется; завершено; приостановлено; просрочено; требует дополнительного финансирования; готово к внедрению; не имеет определённого потребителя; предлагается к прекращению.

**2. Сводная матрица НИОКР (пример формы — значения условные):**

| Шифр | Наименование | Стоимость, млн ₽ | Готовность | Балл I | Предложение |
| --- | --- | --- | --- | --- | --- |
| НИОКР-01 | Разработка А | 120 | 85 % | 91 | Внедрить |
| НИОКР-02 | Разработка Б | 250 | 55 % | 74 | Продолжить |
| НИОКР-03 | Разработка В | 80 | 30 % | 48 | Пересмотреть |
| НИОКР-04 | Разработка Г | 65 | 20 % | 25 | Прекратить |

Матрица синхронизируется с листом «Портфель» Excel-шаблона (категория по баллу рассчитывается автоматически).

**3. Главные выводы руководителя подразделения:** приоритетные НИОКР; наибольшие проблемы; дублирующие разработки; результаты к внедрению в ближайший год; перераспределение ресурсов; решения, требуемые от руководства организации.

## Финальный слайд. Регламент и уровни представления

**Регламент подготовки материалов на аудит:**

| Этап | Ответственный | Результат |
| --- | --- | --- |
| 1. Подготовка информации | Руководитель НИОКР | Заполненные 11 слайдов |
| 2. Проверка данных | Финансовое подразделение | Подтверждение затрат |
| 3. Проверка результатов | Технические специалисты | Подтверждение готовности |
| 4. Проверка документации | Служба управления НИОКР | Подтверждение исполнения |
| 5. Представление | Руководитель структурного подразделения | Доклад комиссии (10–15 мин) |
| 6. Независимая оценка | Аудиторская комиссия | Баллы чек-листа, замечания |
| 7. Принятие решения | Руководство организации | План дальнейших действий |

**Три уровня представления информации:**

- **Уровень 1 — руководство организации:** один сводный слайд по портфелю + по одному слайду на проблемную/стратегическую НИОКР. Цель: управленческие решения и перераспределение ресурсов.
- **Уровень 2 — аудиторская комиссия:** полная презентация из 11 слайдов на каждую НИОКР. Цель: комплексная проверка по чек-листу (27 вопросов, интегральный балл I).
- **Уровень 3 — исполнитель и профильные специалисты:** приложения (ТЗ, календарные планы, финансовые расшифровки, РКД, протоколы испытаний, акты, перечни результатов, расчёты). Цель: доказательная проверка достоверности.

**Итог аудита:** портфельная карта НИОКР организации — распределение разработок по категориям «продолжить / внедрить / модернизировать / объединить / приостановить / прекратить». Цель системы — переход от учёта количества НИОКР к управлению результативностью всего научно-технического портфеля.
