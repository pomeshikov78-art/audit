# ДЕТАЛИЗИРОВАННЫЕ КРИТЕРИИ ОЦЕНКИ

## Блок II «Оценка эффективности НИОКР» (вес 35 %, вопросы 10–18)

Документ развивает чек-лист аудита НИОКР (финальная версия 2.0) и устанавливает для каждого из девяти вопросов блока детальные якорные описания баллов 5 / 4 / 3 / 1 / 0, состав документальной базы, условия применения ответа «Н/П» и типичные ошибки, которые аудитору следует контролировать.

---

## 1. Общие положения

1. **Балл выставляется по якорю, а не «по ощущению».** Каждый балл привязан к проверяемому описанию. Если ситуация находится между якорями, выбирается **меньший** балл (принцип консервативности аудитора).
2. **Количественные пороги являются рекомендуемыми.** Организация вправе уточнить их в своём регламенте аудита (например, с учётом длительности НИОКР, типа разработки — фундаментальная / прикладная / опытно-конструкторская). Пороги должны быть едиными для всех проверяемых НИОКР в рамках одного аудиторского цикла — иначе интегральные баллы несопоставимы.
3. **Правило документального подтверждения действует без исключений:** баллы 4 и 5 выставляются только при наличии документа из перечня «документальная база». Устные пояснения исполнителя фиксируются в комментарии, но балл не повышают.
4. **Процентная база отклонений.** Отклонение по срокам рассчитывается от договорной (плановой) продолжительности этапа или НИОКР в целом: δт = (Т факт − Т план) / Т план. Отклонение по бюджету: δб = (З факт − З план) / З план. Для незавершённых НИОКР используется прогноз итоговой стоимости.
5. **Ответ «Н/П»** допускается только при объективной неприменимости критерия (случаи перечислены в каждом критерии) с обязательным письменным обоснованием. «Н/П» исключает вопрос из числителя и знаменателя расчёта блока: P₂ = S₂ / (5·N₂).

**Рекомендуемая сводная калибровочная таблица порогов (для критериев 11, 12, 16):**

| Отклонение | Балл |
| --- | --- |
| ≤ 5 % (в пределах планового резерва) | 5 |
| > 5 % и ≤ 15 % (при документально подтверждённых уважительных причинах) | 4 |
| > 15 % и ≤ 30 % | 3 |
| > 30 % и ≤ 50 % | 1 |
| > 50 % либо отклонение не может быть подтверждено расчётом | 0 |

## 2. Критерий 10. Достигнуты ли цели и результаты, установленные техническим заданием?

**Что оценивается:** степень соответствия фактических результатов требованиям ТЗ (технического предложения, договора) по составу результатов и по количественным характеристикам.

**Документальная база:** ТЗ с изменениями и дополнениями; отчёты по этапам (ГОСТ 7.32); акты приёмки этапов; программа и методики испытаний; протоколы испытаний; акты приёмки НИОКР заказчиком; переписка о согласовании изменений.

| Балл | Якорное описание |
| --- | --- |
| 5 | Все пункты ТЗ выполнены; 100 % количественных характеристик подтверждены протоколами испытаний; изменения ТЗ (если были) согласованы с заказчиком в установленном порядке |
| 4 | Выполнено ≥ 90 % пунктов ТЗ; отклонения по отдельным второстепенным характеристикам не влияют на применение результата; зафиксированы актами и планами устранения |
| 3 | Выполнено 70–90 % пунктов ТЗ; часть ключевых характеристик не подтверждена испытаниями; изменения ТЗ частично не оформлены |
| 1 | Выполнено 50–70 % пунктов ТЗ; ключевые цели не достигнуты либо подменены более простыми результатами; изменения ТЗ не согласованы |
| 0 | Выполнено < 50 % пунктов ТЗ; заявленные результаты отсутствуют или не подтверждены ни одним документом; фактически выполнен иной объём работ |

**Когда применим «Н/П»:** практически не применим — ТЗ есть у любой НИОКР. Возможный случай: работы велись до формального утверждения ТЗ (инициативный этап), и сравнивать не с чем; обоснование обязательно.

**Типичные ошибки и манипуляции:** «переутверждение» ТЗ задним числом под фактически полученный результат; приёмка этапа актом без протоколов испытаний; подмена количественных характеристик качественными формулировками; учёт результатов смежных работ как собственных.

## 3. Критерий 11. Соблюдены ли установленные сроки выполнения НИОКР?

**Что оценивается:** отклонение фактических сроков от календарного плана по НИОКР в целом и по ключевым этапам; обоснованность причин отклонений.

**Документальная база:** календарный план (договорной и с изменениями); акты сдачи-приёмки этапов с датами; приказы и протоколы о переносе сроков; дополнительные соглашения; отчёты о ходе работ; переписка с заказчиком и поставщиками.

| Балл | Якорное описание |
| --- | --- |
| 5 | δт ≤ 5 % (или ≤ 1 месяца при длительности НИОКР до 2 лет); все ключевые этапы завершены в плановые даты |
| 4 | 5 % < δт ≤ 15 %; просрочены некритические этапы; причины документально подтверждены и уважительны (срыв поставки, изменение требований заказчика) |
| 3 | 15 % < δт ≤ 30 %; просрочен один-два этапа критического пути; прогноз завершения реалистичен и обеспечен ресурсами |
| 1 | 30 % < δт ≤ 50 %; систематические переносы сроков; причины не подтверждены документами либо повторяются из этапа в этап |
| 0 | δт > 50 %; конечный срок сорван без оформленного продления; календарный план не ведётся или не отражает фактическое состояние |

**Когда применим «Н/П»:** НИОКР завершена и принята заказчиком в срок — вопрос не исключается, а оценивается по факту (5 баллов при отсутствии просрочек). «Н/П» возможен только для работ, ведущихся менее одного отчётного периода с момента утверждения плана.

**Типичные ошибки и манипуляции:** перенос сроков допсоглашениями «в обмен» на другие уступки без анализа причин; манипуляции датами актов (этап «сдаётся» формально, работы продолжаются); отсутствие обновлённого прогноза завершения; сокрытие просрочки отчётностью «по вехам», а не по содержанию.

## 4. Критерий 12. Соблюдён ли утверждённый бюджет НИОКР?

**Что оценивается:** отклонение фактических (и прогнозных итоговых) затрат от утверждённой стоимости; качество учёта и обоснованность корректировок бюджета.

**Документальная база:** смета (калькуляция) по статьям; данные раздельного учёта затрат по НИОКР; акты и платёжные документы; дополнительные соглашения об изменении цены; справки финансового подразделения о факте и прогнозе затрат.

| Балл | Якорное описание |
| --- | --- |
| 5 | δб ≤ 5 %; раздельный учёт ведётся корректно по всем статьям; корректировок не было либо они согласованы |
| 4 | 5 % < δб ≤ 15 %; отклонения объяснены объективными причинами (рост цен на комплектующие, изменение объёмов), согласованы с заказчиком |
| 3 | 15 % < δб ≤ 30 %; перерасход частично не обоснован; учёт ведётся с замечаниями |
| 1 | 30 % < δб ≤ 50 %; существенный перерасход без согласования; учёт не позволяет достоверно определить затраты по НИОКР |
| 0 | δб > 50 % либо затраты не подтверждены первичными документами; выявлены признаки нецелевого использования средств |

**Когда применим «Н/П»:** не применим в обычном порядке. Исключение: инициативные работы без утверждённой сметы (обоснование обязательно; рекомендуется вместо «Н/П» оценивать качество постатейного учёта).

**Типичные ошибки и манипуляции:** «размазывание» накладных расходов между несколькими НИОКР в пользу более финансируемой; оплата этапов, не подтверждённых актами; использование авансов смежных контрактов; занижение прогноза итоговой стоимости для прохождения согласований.

## 5. Критерий 13. Рационально ли использованы трудовые и материальные ресурсы?

**Что оценивается:** соответствие трудозатрат и закупок достигнутым результатам; загрузка исполнителей; обоснованность привлечённых соисполнителей.

**Документальная база:** табели и отчёты о трудозатратах по НИОКР; штатная расстановка команды; нормы/плановые калькуляции трудозатрат; договоры с соисполнителями и акты к ним; документы по закупкам (оборудование, комплектующие, материалы); акты списания материалов.

| Балл | Якорное описание |
| --- | --- |
| 5 | Трудозатраты в пределах плановой калькуляции (±10 %); загрузка ключевых исполнителей ≥ 85 %; закупки соответствуют спецификациям и фактически использованы; услуги соисполнителей обоснованы отсутствием собственных компетенций |
| 4 | Отклонение трудозатрат ≤ 25 % при подтверждённом росте объёма работ; отдельные закупки произведены с запасом, но учтены |
| 3 | Трудозатраты превышают плановые на 25–50 % без соразмерного роста результата; часть закупленного не использована; загрузка исполнителей нерегулярна |
| 1 | Существенное превышение трудозатрат и закупок над результатом; дублирование функций соисполнителей и головного исполнителя; значительные непроизводительные расходы |
| 0 | Учёт трудозатрат не ведётся или фиктивен; закупленные ресурсы не оприходованы / не найдены; результат несоразмерен затраченным ресурсам |

**Когда применим «Н/П»:** работы выполнялись без затрат трудовых ресурсов организации (полностью сторонним исполнителем по договору — тогда оцениваются критерии 12 и 16).

**Типичные ошибки и манипуляции:** «мёртвые души» в отчётах о трудозатратах; закупка оборудования «на будущее» без связи с ТЗ; вывод работ на аффилированных соисполнителей; списание материалов без привязки к изготовленным изделиям.

## 6. Критерий 14. Достигнут ли запланированный научно-технический уровень?

**Что оценивается:** подтверждённость фактических характеристик результата расчётами, экспериментами и испытаниями; сопоставимость с требованиями ТЗ и лучшим аналогами.

**Документальная база:** отчёты о НИР, расчёты и модели; программы и методики испытаний; протоколы предварительных, приёмочных, межведомственных испытаний; акты изготовления опытного образца; сравнительные таблицы с аналогами; публикации и патентные материалы.

| Балл | Якорное описание |
| --- | --- |
| 5 | Все ключевые характеристики подтверждены испытаниями (протоколы); уровень не ниже ТЗ; проведено сопоставление с аналогами — преимущество подтверждено; воспроизводимость результата продемонстрирована |
| 4 | Характеристики подтверждены испытаниями не менее чем на 90 %; отдельные параметры подтверждены расчётом/моделированием с планом натурной проверки |
| 3 | Подтверждена только часть характеристик (50–90 %); сопоставление с аналогами формальное или устарело; отдельные расхождения с ТЗ не проанализированы |
| 1 | Большинство характеристик не подтверждено (> 50 %); доказательства ограничены расчётами без экспериментальной проверки; фактический уровень ниже аналогов |
| 0 | Характеристики не подтверждены; заявленный научно-технический уровень недостижим в рамках выбранной концепции; результат не воспроизводится |

**Когда применим «Н/П»:** этап НИОКР, по которому испытания программой не предусмотрены (например, аналитический этап НИР) — при наличии утверждённой программы этапа.

**Типичные ошибки и манипуляции:** испытания «для протокола» на заниженных режимах; подмена показателей ТЗ удобными для демонстрации; использование устаревших данных об аналогах; «успешные» результаты без оценки воспроизводимости.

## 7. Критерий 15. Сформирован ли реальный научно-технический задел?

**Что оценивается:** наличие повторно используемых результатов: РКД/ЭД/ПД, ПО, методики, технологии, прототипы, РИД, компетенции команды.

**Документальная база:** ведомости документов (РКД, ЭД, ПД); реестры ПО и свидетельства о регистрации; патенты и заявки; акты на опытные образцы; методики и стандарты организации; сведения о подготовленных кадрах (аспирантура, публикации); решения о применении задела в других работах.

| Балл | Якорное описание |
| --- | --- |
| 5 | Задел сформирован и оформлен: комплект документации утверждён, ПО зарегистрировано, РИД поставлены на учёт, прототипы хранятся и пригодны к развитию; есть подтверждённые случаи повторного использования |
| 4 | Задел сформирован, отдельные элементы не оформлены (идёт регистрация РИД, документация на стадии утверждения) с планом-графиком |
| 3 | Задел частично пригоден к повторному использованию; документация неполная; РИД не поставлены на учёт; использование в других работах не планируется |
| 1 | Результаты существуют только «в головах исполнителей» или в черновых материалах; повторное использование потребует фактического повторения работ |
| 0 | Задел отсутствует: документация утрачена/не создана, РИД нет, прототипы списаны или не изготовлены |

**Когда применим «Н/П»:** не применим — задел оценивается у любой НИОКР; для незавершённых работ оценивается сформированная часть.

**Типичные ошибки и манипуляции:** выдача черновых отчётов за документацию; регистрация ПО, не связанного с результатом; непостановка РИД на бухгалтерский учёт; утрата данных при увольнении исполнителей (отсутствие депонирования).

## 8. Критерий 16 ★. Все ли затраты связаны с результатом НИОКР; нет ли повторных оплат?

**Что оценивается:** «чистота» структуры затрат: отсутствие непрофильных расходов, двойных оплат одних и тех же работ, полнота первичных документов.

**Документальная база:** постатейная расшифровка затрат; первичные документы (акты, накладные, УПД); реестр этапов и закрытых работ (для контроля дублей); договоры и акты соисполнителей; результаты выборочной сверки финансовым подразделением.

| Балл | Якорное описание |
| --- | --- |
| 5 | ≥ 95 % затрат подтверждены первичными документами и связаны с результатом; дубли не выявлены; непрофильные расходы отсутствуют |
| 4 | 90–95 % затрат подтверждены; единичные замечания устранены или устранимы в рабочем порядке |
| 3 | 75–90 % затрат подтверждены; есть непрофильные расходы небольшой величины; выявлены спорные позиции, требующие разъяснений |
| 1 | 50–75 % затрат подтверждены; существенные непрофильные расходы; выявлен хотя бы один факт повторной оплаты (возврат не произведён) |
| 0 | < 50 % затрат подтверждены; системные непрофильные расходы; повторные оплаты не возвращены; признаки нецелевого использования |

**Когда применим «Н/П»:** затраты по НИОКР не производились (например, инициативная работа силами сотрудников без отдельного финансирования — оценивается критерий 13).

**Типичные ошибки и манипуляции:** закрытие одного содержания работ по двум этапам/договорам; включение в себестоимость НИОКР расходов других проектов; оплата «консультационных услуг» без внятного результата; формальные акты без дат и объёмов.

---

## 9. Критерий 17 ★. Учтены ли и используются ли закупленные, но не использованные ресурсы?

**Что оценивается:** состояние остатков оборудования, материалов и комплектующих, закупленных под НИОКР; их учёт, сохранность и возможность полезного использования.

**Документальная база:** реестр закупок под НИОКР; данные складского учёта и инвентаризации; акты списания; ведомости остатков; решения о перераспределении имущества на другие работы.

| Балл | Якорное описание |
| --- | --- |
| 5 | Неиспользованных остатков нет либо они ≤ 5 % стоимости закупок; всё учтено, принято решение о применении в других работах |
| 4 | Остатки ≤ 15 % стоимости закупок; учтены; план использования определён |
| 3 | Остатки 15–30 %; учтены, но решение об использовании не принято; часть комплектующих устарела |
| 1 | Остатки 30–50 %; учёт частичный; имущество простаивает более года; признаки неликвидов |
| 0 | Остатки > 50 % либо имущество не найдено/не оприходовано; закупки под НИОКР фактически не использованы |

**Когда применим «Н/П»:** закупки оборудования, материалов и комплектующих под НИОКР не производились (подтверждается отсутствием договоров закупки по данному шифру).

**Типичные ошибки и манипуляции:** закупка «с запасом» без обоснования; комплектующие, снятые с производства, пока закупка числится «под проект»; отсутствие инвентаризации остатков; перенос остатков между проектами без документов.

## 10. Критерий 18 ★. Обоснована ли оставшаяся потребность в финансировании?

**Что оценивается:** качество оценки затрат до завершения: наличие детальной сметы оставшихся работ, реалистичность прогноза итоговой стоимости, учёт рисков роста затрат.

**Документальная база:** смета оставшихся работ (по статьям и этапам); обновлённый календарный план; прогноз итоговой стоимости с допущениями; реестр рисков с финансовой оценкой; подтверждение источников финансирования; справки о состоянии авансовых платежей.

| Балл | Якорное описание |
| --- | --- |
| 5 | Детальная смета оставшихся работ утверждена; прогноз итоговой стоимости отклоняется от плановой ≤ 10 %; риски роста затрат оценены и покрыты резервом; источники финансирования подтверждены |
| 4 | Смета имеется, прогноз отклоняется ≤ 20 %; допущения раскрыты; отдельные позиции требуют уточнения |
| 3 | Оценка потребности укрупнённая (без постатейной детализации); прогноз отклоняется на 20–40 %; риски не оценены количественно |
| 1 | Потребность заявлена «от достигнутого» без расчёта; прогноз отклоняется > 40 %; источники финансирования не определены |
| 0 | Остаток потребности не рассчитан; ранее заявленные прогнозы систематически занижались; продолжение работ без дополнительного анализа нецелесообразно |

**Когда применим «Н/П»:** НИОКР завершена, принята заказчиком и финансирование закрыто (подтверждается актом и справкой финансового подразделения); работы официально прекращены.

**Типичные ошибки и манипуляции:** занижение прогноза для получения согласования «ещё одного этапа»; неучтённые затраты на подготовку производства и сертификацию (см. критерий 25 блока III); прогноз без учёта инфляции и валютных рисков по импортным комплектующим.

## 11. Порядок оценки и расчёта по блоку II

1. По каждому из девяти критериев аудитор фиксирует: ответ по шкале, балл (автоматически), ссылку на подтверждающий документ в комментарии, при «Н/П» — обоснование.
2. Сырой балл блока: S₂ = сумма баллов применимых критериев (0–45).
3. Число применимых критериев: N₂ = количество критериев без ответа «Н/П» (0–9).
4. Процент выполнения: P₂ = S₂ / (5 · N₂).
5. Взвешенный вклад блока: B₂ = 35 · P₂ (0–35 баллов интегрального показателя).

**Пример.** Ответы по критериям 10–18: 4, 3, 3, 4, 3, 3, 4, Н/П, 1. Тогда S₂ = 25, N₂ = 8, P₂ = 25/40 = 62,5 %, B₂ = 35 × 0,625 = 21,88 балла. Основной «вклад» в снижение оценки дали критерии 11 (сроки) и 18 (остаточное финансирование) — именно они должны попасть в перечень мероприятий акта оценки.
